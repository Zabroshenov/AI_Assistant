# 🎙️ AI Assistant (Голосовой ассистент)

Программа-ассистент, которая понимает голосовые команды, общается с помощью нейросети, ищет музыку и управляет компьютером.

## 🚀 Быстрый старт

1. **Распакуйте архив** в любую удобную папку (например, на Рабочий стол).
2. **Запустите `Ассистент.exe`**.
   * *Если Windows SmartScreen выдаст предупреждение — нажмите «Подробнее» -> «Выполнить в любом случае».*
3. **Введите API-ключ.** При первом запуске внизу окна появится поле. Вставьте ключ и нажмите **«Сохранить»**.
4. **Разрешите доступ к микрофону** (если Windows спросит).
5. **Скажите: «Привет»** — ассистент ответит голосом.

## 🎤 Голосовые команды

| Команда | Действие |
| :--- | :--- |
| «Включи [название песни]» | Открывает YouTube с результатами поиска в вашем браузере по умолчанию |
| «Пауза» / «Продолжи» | Ставит медиа на паузу или продолжает воспроизведение |
| «Следующий трек» / «Предыдущий» | Переключает треки |
| «Громче» / «Тише» | Регулирует громкость системы |
| «Выключи звук» | Включает беззвучный режим |
| «Который час» | Сообщает текущее время |
| «Какая погода» | Сообщает погоду в вашем городе |
| «Выход» / «Закройся» | Завершает работу программы |

*Любые другие фразы отправляются нейросети для поддержания беседы.*

## 🖱️ Управление интерфейсом

*   **Перетаскивание окна:** Потяните за верхнюю зеленую шапку `>>> ASSISTANT_CONSOLE_v1.0 <<<`.
*   **Свернуть в трей:** Нажмите кнопку **«—»** (программа продолжит слушать в фоне).
*   **Закрыть программу:** Нажмите кнопку **«×»**.
*   **Пауза / Слушать:** Нажмите **`Tab + Z`** (ассистент перестанет слушать микрофон, пока вы не нажмете снова).

## ⚠️ Важные нюансы

1.  **Интернет:** Программа использует онлайн-сервисы для распознавания речи, нейросети и озвучки.
2.  **Микрофон:** Ассистенту нужен доступ к микрофону. Если он молчит — проверьте настройки конфиденциальности Windows.
3.  **Файлы программы:** Рядом с `.exe` программа создаст три объекта. **Не удаляйте их:**
    *   `api_key.txt` — ваш ключ.
    *   `chat_memory.json` — история диалога (память).
    *   `tts_cache/` — кэш озвучки (ускоряет ответы).
4.  **Браузер:** Музыка открывается в браузере, установленном у вас по умолчанию (Chrome, Edge, Firefox и т.д.).
5.  **Антивирус:** Из-за специфики упаковки Python-программ в `.exe`, антивирус может ругаться. Это ложное срабатывание.# AI_Assistant
